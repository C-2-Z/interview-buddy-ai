# 数据结构与算法面试知识点

## 数据结构
- **数组与链表**：动态数组扩容策略、双向链表与跳表
- **栈与队列**：单调栈（下一个更大元素）、优先队列（堆实现）
- **树**：二叉树遍历（前/中/后序、层序）、BST、AVL 树、红黑树、Trie 树、线段树
- **图**：邻接矩阵 vs 邻接表、拓扑排序、Dijkstra / Floyd / Bellman-Ford、并查集
- **哈希表**：哈希冲突解决（链地址法/开放地址法）、布隆过滤器

## 算法
- **排序**：快速排序/归并排序/堆排序的复杂度与实现、排序稳定性的应用场景
- **搜索**：二分搜索及其变体（旋转数组、搜索区间）、DFS / BFS 模板
- **动态规划**：背包问题（0-1 / 完全）、最长子序列（LCS/LIS）、区间 DP、树形 DP
- **贪心**：区间调度、分发糖果、Huffman 编码
- **字符串**：KMP、Manacher（最长回文子串）、Rabin-Karp 滚动哈希

## 复杂度分析
- 大 O 表示法、均摊分析（Amortized Analysis）、主定理（Master Theorem）

## 常考题型示例
1. 实现一个 LRU 缓存（要求 get 和 put 都是 O(1)）
2. 给定一个数组和一个目标值，找出数组中两个数的和等于目标值（两数之和）
3. 二叉树的层序遍历如何实现？（BFS + 队列）
4. 最长递增子序列（LIS）的 O(n log n) 解法？
5. 如何判断一个链表是否有环？找到环的入口？
6. 编辑距离（Levenshtein Distance）的 DP 解法？
7. 设计一个支持在 O(1) 时间内获取最小值的栈
8. 并查集实现，如何进行路径压缩和按秩合并的优化？
