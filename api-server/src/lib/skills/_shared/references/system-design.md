# 系统设计面试知识点

## 设计方法论
- **需求分析**：功能需求与扩展需求（QPS / DAU / 存储量估算）、边界条件
- **容量估算**：QPS 计算、带宽估算、存储量估算（2-5-10 原则）
- **分层架构**：接入层（DNS/CDN）→ 应用层（微服务）→ 数据层（读写分离/分片）

## 核心组件
- **负载均衡**：Nginx / LVS / F5、四层 vs 七层、一致性哈希
- **缓存**：本地缓存（Caffeine） vs 分布式缓存（Redis）、多级缓存策略
- **消息队列**：Kafka / RocketMQ 选型、削峰填谷、顺序消息、死信队列
- **分布式 ID**：雪花算法（Snowflake）、UUID、数据库自增
- **分布式事务**：CAP 理论、BASE、2PC / TCC / Saga / 最终一致性
  
## 典型场景
- **短链接服务**：发号器、Bloom Filter 防重复、跳转 301/302
- **秒杀系统**：流量削峰、库存预热、限流（令牌桶/漏桶）、接口防刷
- **Feed 流**：推模式 vs 拉模式 vs 推拉结合、热用户冷启动
- **即时通讯**：WebSocket 长连接、心跳保活、离线消息、ACK 确认

## 常考题型示例
1. 设计一个短链接系统，如何生成短链接？如何支持高并发访问？
2. 如何设计一个支持千万 DAU 的实时 Feed 流系统？
3. 如果让你设计一个秒杀系统，你怎么做架构设计？
4. 分布式环境下，如何保证 ID 的唯一性和递增性？
5. 谈谈你理解的高可用架构设计原则（冗余、降级、限流、熔断）
6. 分布式事务有哪几种实现方案？各自的优缺点？
