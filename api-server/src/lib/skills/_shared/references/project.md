# 项目经历面试参考

## 项目表达框架（STAR 原则）
- **S (Situation)**：项目背景与目标，为什么要做这个项目
- **T (Task)**：你在其中的具体角色和职责
- **A (Action)**：你做了什么？技术选型、方案设计、关键决策
- **R (Result)**：最终效果如何？量化数据（性能提升%、用户增长、成本降低）

## 常见考察角度
- **技术深度**：项目中的难点是什么？你是怎么解决的？还有没有更好的方案？
- **架构设计**：系统的整体架构是什么样的？为什么做这样的架构选择？
- **团队协作**：项目涉及哪些团队？跨团队协作中遇到过什么问题？
- **复盘反思**：如果现在重新做一次，哪些地方你会做得不一样？

## 评分维度
- 项目复杂度：项目体量、涉及团队规模、技术难度
- 个人贡献：是否核心参与者、决策参与度、技术深度
- 结果导向：是否上线、数据效果、业务影响
- 表达清晰：能否把复杂的事情讲清楚、逻辑层次分明
- 思考深度：是否有反思、有提炼、有沉淀方法论
