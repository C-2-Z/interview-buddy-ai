# 产品战略面试知识点

## 市场分析
- **行业分析**：PEST 分析、波特五力模型、SWOT 分析（优势/劣势/机会/威胁）
- **竞争分析**：市场定位矩阵、差异化策略、护城河分析
- **商业模式**：商业模式画布（Value Proposition / Revenue Streams / Cost Structure）、付费模式（订阅/Freemium/广告/交易抽成）

## 增长策略
- **增长飞轮**：复利效应、网络效应（双边/单边/同边）、规模效应
- **用户生命周期管理**：拉新（渠道评估/病毒系数 K-factor）、促活（激活时刻 Aha Moment）、留存（粘性/召回）、变现（定价策略/转化优化）
- **北极星拆解**：从公司级战略到产品级指标的拆解方法

## 产品决策
- **决策框架**：RICE（Reach / Impact / Confidence / Effort）、ICE（Impact / Confidence / Ease）
- **0-1 产品**：PMF（Product-Market Fit）验证方法、问题-解决方案匹配

## 常考题型示例
1. 如果让你进入一个新的市场，你怎么判断应不应该进入？如何切入？
2. 讲一个你印象深刻的增长案例，它是如何实现用户增长的？核心驱动力是什么？
3. 什么是网络效应？举一个你身边的产品例子说明网络效应如何形成？
4. 如何判断一个产品达到了 Product-Market Fit（PMF）？
5. 公司资源有限，多个需求方都在要资源，你怎么决定优先做什么？
6. 如何为一个成熟产品找到新的增长点？你常用的思考框架是什么？
7. 价值主张画布（Value Proposition Canvas）怎么用？你的产品满足了用户的什么"要做的事"（Jobs to be Done）？
8. 如果你要为产品增加一个付费功能，你会怎么设计和定价？
9. 我们的竞争对手做了一个新功能，我们是否应该跟进？你的分析框架是什么？
10. 讲一下你用过的一招"降维打击"式的产品策略？
