# 数据驱动产品面试知识点

## 核心指标
- **指标分类**：北极星指标（North Star Metric）、AARRR（海盗指标）、Vanity Metrics vs Actionable Metrics
- **用户增长**：CAC / LTV / ROI、流失率（Churn Rate）、留存率（Retention）、NPS
- **电商/O2O**：GMV / 客单价 / 转化率 / 复购率 / 渗透率
- **内容平台**：DAU / MAU、用户时长、内容消费量、互动率

## 数据分析方法
- **漏斗分析**：各环节转化率、流失节点定位、漏斗对比
- **细分分析**：用户分层（RFM / 行为分群）、同期群分析（Cohort Analysis）
- **归因分析**：首次触点 / 末次触点 / 多触点归因 / Shapley Value
- **A/B 实验**：假设检验、样本量计算、MDE（最小可检测效应）、AA 检验、网络效应下的分流

## 数据工具
- 埋点方案（前端/后端/全链路）、数仓分层（ODS/DWD/DWS/ADS）
- SQL 基础、数据可视化原则

## 常考题型示例
1. 设计一个电商产品的指标体系，北极星指标选什么？为什么？
2. 一个功能上线后核心指标下降，你的排查思路是什么样的？
3. 如何判断一个 A/B 实验是否有效？什么叫统计显著性？容易踩哪些坑？
4. 讲讲你做过的一个数据驱动的产品决策案例，数据是怎么影响决策的？
5. 同期群分析（Cohort Analysis）有什么用？举个实际场景。
6. 不同用户分群方法（RFM、行为分群、价值分群）各自的适用场景？
7. 如何衡量产品的用户体验？是否有量化的方法？
8. 一个功能上线后 DAU 涨了，但留存没变，你怎么评估这个功能的效果？
