# 产品思维与设计面试知识点

## 产品思维
- **用户中心设计**：用户画像（Persona）、用户旅程地图（User Journey Map）、同理心地图
- **需求分析**：5W1H 方法、KANO 模型（基本型/期望型/兴奋型需求）、MoSCoW 优先级（Must/Should/Could/Won't）
- **产品规划**：产品愿景、Roadmap 制定（Now-Next-Later）、OKR 分解、MVP 定义
- **用户体验**：交互设计原则（Nielsen 十大可用性原则）、信息架构、Fitts 定律

## 需求方法
- **用户调研**：深度访谈、焦点小组、问卷调查、可用性测试、日志分析
- **需求文档**：BRD / MRD / PRD 文档结构、验收标准（Acceptance Criteria）
- **原型设计**：低保真 vs 高保真原型、交互原型工具（Figma / Axure）

## 常考题型示例
1. 如何判断一个需求是真的需求还是伪需求？你用什么方法验证？
2. 讲一下你用过的最满意/最不满意的产品，为什么？如果是你来做，你会怎么改进？
3. 如何为一款新的社交产品制定 MVP 范围？怎么确定第一批核心功能？
4. 产品上线后发现数据不达预期，你的排查思路是什么？
5. 如何平衡用户体验和商业目标之间的矛盾？举例说明。
6. 给你一个开放问题：设计一个面向 60 岁以上用户的在线问诊产品，你会怎么做？
7. OKR 和 KPI 有什么区别？在制定产品目标时如何运用 OKR？
8. 需求评审会上开发说实现不了，你怎么沟通和推进？
