# 机器学习基础面试知识点

## 监督学习
- **线性模型**：线性回归（最小二乘法/梯度下降）、逻辑回归（交叉熵损失、Softmax）、正则化（L1 Lasso / L2 Ridge / ElasticNet）
- **树模型**：决策树（ID3 / C4.5 / CART）、随机森林、GBDT / XGBoost / LightGBM 原理
- **SVM**：最大间隔分类器、核技巧（RBF/Poly）、对偶问题、软间隔
- **贝叶斯**：朴素贝叶斯（特征独立性假设）、高斯/多项/伯努利分布
- **集成学习**：Bagging（降低方差）、Boosting（降低偏差）、Stacking

## 无监督学习
- **聚类**：K-Means（K 选择/初始点优化）、DBSCAN、层次聚类
- **降维**：PCA（主成分分析）、SVD、t-SNE

## 评估与调优
- **评估指标**：准确率/精确率/召回率/F1 / AUC-ROC / MSE/MAE / R²
- **过拟合**：交叉验证、正则化、Dropout、Early Stopping
- **特征工程**：缺失值处理、编码（One-Hot/Label/Count）、标准化（Z-score / MinMax）

## 常考题型示例
1. 逻辑回归中为什么用交叉熵损失而不用均方误差？
2. 决策树如何选择分裂特征？信息增益 vs 信息增益比 vs 基尼系数的区别？
3. XGBoost 相比 GBDT 做了哪些优化？
4. 什么是偏差-方差权衡？Bagging 和 Boosting 分别如何影响偏差和方差？
5. AUC 的含义是什么？怎么计算？AUC=0.5 和 AUC=0.9 分别代表什么？
6. K-Means 初始化时 K 值怎么确定？初始中心点怎么选可以减少陷入局部最优？
7. 特征工程中如何处理类别特征和高基数特征？
8. L1 和 L2 正则化的区别？为什么 L1 产生稀疏解？
