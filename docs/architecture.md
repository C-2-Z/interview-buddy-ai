# AI 面试模拟器 — 架构设计文档

> 版本: 1.0 | 最后更新: 2026-07-11

---

## 1. 系统概述

AI 面试模拟器是一个基于 AI 的面试练习平台。用户选择岗位和难度后，系统自动生成面试题，通过多轮对话模拟真实面试流程，逐题评分并生成综合能力报告。

系统采用前后端分离架构，前端使用 TanStack React Start (SSR) 渲染，后端使用 Hono 框架提供 RESTful API 和 WebSocket 服务。
