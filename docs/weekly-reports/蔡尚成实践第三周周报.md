**四、遇到的问题与困难**

- **技术问题：**
   - 语音 WebSocket 在 Railway 生产环境初始化失败：原因为 Supabase client 在 Railway 的 serverless 环境下 `connect.socket.io` 端点和 WSS 检测与本地环境不同。通过新增 `voice_socket_tickets` 表分离令牌生成与认证流程，并在 `supabase.ts` 中跳过 WebSocket 冷启动，分别修复了两类连接失败场景。
   - 面试 Agent FSM 的状态转换边界设计：需兼顾新 Agent（v3）的主流程和旧状态机（v1/v2）的兼容。通过 FSM 设计文档固化转换规则，并在 `interview-agent.graph.ts` 中显式定义状态节点和边，避免了状态漂移。
   - 密码恢复的跨端回跳：Tauri 深链处理需要同时支持 web 端（点击邮件链接）和桌面端（注册自定义协议）。通过 `tauri-deep-link` 模块和运行时配置实现了统一跳转处理。
 - **需要帮助或待解决：**
   - 语音面试的端到端延迟测量和成功率基线尚未建立，后续需要补充量化指标。
