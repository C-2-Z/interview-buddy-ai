# 项目概述

> 状态：当前；最后核验：2026-07-16

## 1. 产品简介

EZMock 是一个 AI 驱动的面试练习平台。它把岗位目标、个人经历和外部知识组织成一场可恢复的模拟面试，在多轮对话后给出可追溯的能力评分和改进建议。

与普通聊天机器人不同，EZMock 的业务控制权不交给模型：题量、角色顺序、追问上限、评分维度、幂等处理和结束条件由代码与数据库约束；模型只在受控输入和严格输出格式内完成问题、追问和候选评分生成。

## 2. 目标用户与场景

### 2.1 目标用户

- 准备校招、社招、转岗或晋升面试的候选人。
- 希望围绕具体 JD、公司或个人简历训练的用户。
- 需要文字复盘、语音模拟和长期弱项追踪的学习者。

### 2.2 典型场景

1. 快速模拟：选择岗位、难度和题量后立即训练。
2. JD 定向：粘贴岗位需求，围绕职责和能力要求提问。
3. 简历深挖：绑定已解析简历，追问项目、技能和成果。
4. 公司定向：结合目标公司与受控联网资料准备问题。
5. 知识库增强：绑定个人 Brain，让 Agent 引用指定材料。
6. 弱项复练：根据报告最低分能力生成下一场训练草稿。

## 3. 核心业务闭环

```text
注册/登录
  -> 选择文字或语音
  -> 配置岗位、材料和模型
  -> readiness 创建前检查
  -> 创建 agent-v3 会话
  -> 准备策略、研究与首题
  -> 回答、追问、证据提取、逐题评分
  -> 角色接力或下一题
  -> 综合报告
  -> 长期记忆聚合与弱项复练
```

## 4. 产品模式

| 维度     | 可选值                    | 当前规则                                         |
| -------- | ------------------------- | ------------------------------------------------ |
| 交互通道 | `text` / `voice`          | 创建时冻结，不能在同一会话切换                   |
| 体验模式 | `coaching` / `simulation` | 文字固定 coaching，语音固定 simulation           |
| 角色模式 | `single` / `panel`        | single 为通用面试官；panel 为技术、主管、HR 接力 |
| 难度     | 初级/中级/高级            | 影响题目与证据深度                               |
| 题量     | 3–10                      | 创建时冻结                                       |

`coaching` 在过程中展示脱敏活动、证据和逐题反馈；`simulation` 在完成前隐藏这些训练信息，避免破坏真实感。

## 5. 功能全景

- 用户认证与登录态持久化。
- 文字 Agent 工作台与沉浸式语音房间。
- 单角色、多角色面板、角色 Persona 和题量分配。
- Skill、公共题库、JD、公司、简历、Brain、长期记忆和联网研究。
- 输入防护、最多三轮追问、幂等操作、SSE 重放和断线恢复。
- 证据化逐题评分、确定性总分和综合报告。
- 会话暂停、恢复、提前结束、放弃和删除。
- 简历库、公共题库、知识库/RAG、知识图谱和问答。
- 多模型选择和 BYOK 加密存储。
- Web SSR、Native SPA 和 Tauri 2 Windows 壳。

## 6. 技术全景

```text
TanStack React Start / Tauri WebView2
  -> Supabase Auth
  -> HTTPS JSON + SSE + WSS
Hono API
  -> Supabase PostgreSQL/RLS/RPC
  -> LangGraph PostgreSQL Checkpoint
  -> DeepSeek/OpenAI/Anthropic
  -> Qwen ASR/TTS/Embedding
  -> Tavily/Wikimedia
```

## 7. 当前边界

- 新会话只支持 `agent-v3`；v1/v2 仅保留已完成历史记录的只读展示。
- 原始语音不持久化，仅保存最终转写文本。
- Wikimedia 是无 Tavily Key 时的公开知识降级，不等价于全网搜索。
- Windows Tauri 工程已存在，但仍需真实设备、安装升级和签名验收。
- Android/iOS Capacitor 工程尚未建立。
- 历史渐进生成 Worker 已不在当前运行时中。

## 8. 核心术语

| 术语           | 含义                                                 |
| -------------- | ---------------------------------------------------- |
| Agent Snapshot | 与最后已提交事件同水位的最小可恢复视图               |
| Checkpoint     | LangGraph 节点中断/恢复状态，不是业务真相            |
| Workspace      | 页面恢复所需的问题、消息、策略、证据、评分和报告投影 |
| Operation      | 带稳定键的幂等业务操作                               |
| Evidence       | 从候选人消息中引用的原文证据                         |
| Brain          | 用户组织知识文档的集合，可绑定到面试或 QA            |
| Readiness      | 创建前对功能开关、数据库、模型、语音和研究能力的检查 |
