## Unreleased

### Agent 题目多样性与恢复链路

- 新增增量 migration，统一题库岗位族、意图、阶段、题族、质量和启用状态，并扩充内置岗位/角色/难度题池。
- 选题改为硬约束、固定权重软排序、90 天题族轮换与 session 稳定散列；题库无合法候选时才调用三候选模型补题。
- Planner 只在服务端白名单内表达偏好，非法输出修复一次后使用代码 baseline；移除题库搜索工具和固定追问/万能题兜底。
- 新会话冻结 `interactive-v2` Graph 与独立 checkpoint namespace，保留旧 Graph 恢复兼容。
- reasoning 失败可复用原回答和 checkpoint 继续本轮处理；错误 operation 与 `agent.error` 事件只保存稳定脱敏错误码。
- Wikimedia-only 联网研究 readiness 标记为 degraded，前端新增“继续本轮处理”入口。

### 仓库结构

- 将 Web、API 和 Tauri 桌面端整理为 `apps/web`、`apps/api`、`apps/desktop` 三个 npm workspace。
- 根目录改为统一安装、测试、构建、部署和本地启动入口，只保留一份 `package-lock.json`。
- 将基础设施、桌面和验证脚本按职责归入 `scripts/infra`、`scripts/desktop`、`scripts/verify`。
- 保留 Vercel `api/`、Supabase `supabase/` 和本地持久运行时 `.runtime/` 的工具约定位置。

### 文档

- 将用户流程、UI/UX、隐私事件响应、Review、Runbook、监控和 AI 协作纳入核心文档。

- 删除重复的 `docs/README.md` 和 `docs/AGENT.md`，将文档索引合并到根 README。
