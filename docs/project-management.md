## 3. 验收演示路线

1. 产品定位与文字/语音双入口。
2. 创建向导和 readiness。
3. Agent v3 准备、题库优先、回答和追问。
4. 输入 guard、幂等和刷新/SSE 恢复。
5. 证据评分、报告和弱项复练。
6. 简历、知识库或语音任选一条增强链路。
7. 测试、覆盖率、安全边界和 AI 使用反思。

## 4. 推荐边界场景

- 空白/超长回答。
- 复制题目。
- 中英文 Prompt 注入。
- 重复 inputId 和并发 claim。
- 模型非法 JSON/评分。
- SSE 断线/游标过期。
- 恶意网页资料。
- 生产缺少 checkpoint、迁移或 Key。

- checkpoint、事件和日志是否泄露正文或凭据。

## 7. 证据规则

- 不伪造聊天原文、人工 Review、性能截图或测试结果。
- 每份截图记录环境、时间、地址和操作。
- 性能报告使用多样本 P50/P95，不只展示最快值。
- 测试日志不得包含真实 Key、token、简历或回答。
- 生产环境证据采集需要明确授权并以只读为默认。
