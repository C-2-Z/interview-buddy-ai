# Voice session override

- Use the semantic `voice-*` palette on a dark, low-distraction surface.
- Keep navigation reachable but visually quiet; interview status, transcript, and controls own the hierarchy.
- Required states: disconnected, connecting, speaking, listening, thinking, scored, interrupted, and error.
- Recording exposes one primary action: end answer. AI playback exposes interrupt as the contextual action.
- The mobile control dock reserves safe-area padding and never covers transcript content.
- Diagnostics are collapsed by default. User-facing recovery guidance appears before technical details.
