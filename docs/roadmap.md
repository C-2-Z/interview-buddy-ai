# 产品与技术路线图

> 状态：规划；最后核验：2026-07-16

## 1. 当前基线

已完成并进入主干：

- Agent v3 单一运行时、持久 checkpoint、SSE、证据评分和报告。
- 文字/语音双入口、生命周期、历史、弱项复练。
- 简历、题库、Skill、知识库/RAG、Brain、图谱和长期记忆。
- DeepSeek/OpenAI/Anthropic、多模型设置和 BYOK。
- Web SSR、Native SPA 与 Tauri 2 Windows 工程基础。

## 4. P2：能力扩展

- 每题限时模式。
- 编程题编辑器、受限沙箱和 AI 代码评审。
- 报告 PDF 导出。
- Capacitor Android/iOS 工程。
- 中英文切换。
- 分享面试与权限控制。
- Docker/Compose 标准化开发和部署。

## 5. 不再延续的方案

- Agent v1/v2 写状态机。
- 前端根据题号猜测 Agent 阶段。
- 模型自由决定题量、总分或结束条件。
- 将回答正文、密钥或工具全文写入 checkpoint。
- 没有实际消费者却保留“Worker 已可部署”的文档承诺。

## 6. 规划规则

1. 每个路线图项目必须先写验收标准，再进入开发。
2. 数据库或部署类任务必须包含回滚和权限边界。
3. 新功能必须作为独立模块/feature 实现。
4. 状态变化类功能必须覆盖幂等、并发、刷新和失败恢复。
5. 完成后同步更新需求、架构、设计、测试和本路线图。
