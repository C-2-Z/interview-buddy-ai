# 测试与质量保证

> 状态：当前｜维护者：开发与测试团队｜最后核验：2026-07-16｜代码基线：`main@6958ac3`｜事实源：package scripts、现有 `*.test.ts`、构建配置和需求验收标准

## 1. 质量目标

- 关键业务不变量由自动化测试保护，产品主流程由人工验收补充。
- 每个失败必须可定位、可安全重试或有明确退出路径。
- 测试不得依赖生产数据、生产 Key 或不可控外部写操作。
- 测试结果只记录真实执行值；跳过项必须说明条件。

## 2. 测试分层

| 层级       | 关注点                                                | 当前入口                  |
| ---------- | ----------------------------------------------------- | ------------------------- |
| 单元测试   | schema、guard、状态机、Provider、工具和纯业务逻辑     | Node test + `tsx --test`  |
| 模块集成   | Route/Service/Repository、Agent Graph、知识库 OpenAPI | `@ezmock/api` 测试脚本    |

| 人工验收   | 浏览器、真实语音设备、Tauri 和异常恢复                | 按 AC 场景执行            |

## 3. 自动化命令

```powershell
# Monorepo 全量验证
npm test
npm run lint
npm run build
npm run build:api
npm run build:native:dev
npm run verify:native

# API 针对性覆盖率
npm run test:coverage:acceptance -w @ezmock/api

git diff --check
```

`test:coverage:acceptance` 是核心 Agent 服务的针对性覆盖率检查，不等于全仓库覆盖率。Checkpoint 集成测试只有在显式隔离数据库存在时才应运行；未配置时允许测试自我跳过，并必须在报告中注明。

## 4. 必测业务不变量

### 4.1 Agent

- 新会话只能写 `agent-v3`。
- 文字固定 coaching，语音固定 simulation。
- 创建配置被冻结，客户端不能在后续请求篡改模式、用户或版本。
- 题目索引、追问次数、评分、完成和报告状态保持一致。
- 旧 v1/v2 会话不能进入当前交互写链路。
- 选题严格保持角色、难度和主维度，主题只参与软排序；单场排除相同题族，近 90 天优先未见题族。
- 同一 session 重试选择稳定，不同 session 在候选充足时自然轮换；内置岗位矩阵不得调用模型补题。
- Planner 非法偏好只能修复一次后回到代码 baseline，不得淘汰合法题库；题库无候选时模型一次生成 3 个并执行结构和近似去重。
- 不得恢复万能题、固定字数追问决策、伪造评分或伪证据。

### 4.2 输入、并发与恢复

- 空白、超长、复制题目、Prompt 注入和非法 schema 被拒绝或安全引导。
- 相同 `inputId` 不重复创建回答、推进问题或评分。
- 并发 claim 只有一个执行者成功，失败/超时可安全释放或重试。
- SSE 初连、`Last-Event-ID` 重放、游标过期和刷新恢复行为一致。
- Checkpoint 缺失/不可用不会让生产静默退化到内存状态。
- reasoning operation 失败后 `/retry` 复用原 `inputId`、回答与 checkpoint，不重复回答、评分、事件或题目。
- 新会话只进入 `interactive-v2` namespace；缺少 `graphVersion` 的旧 checkpoint 继续由旧 Graph 恢复。

### 4.3 数据与安全

- 用户 A 无法读取、更新或删除用户 B 的会话、简历、知识库、设置或记忆。
- Key 读取不返回明文，错误与日志不包含 Authorization、正文或凭据。
- 业务正文不进入 Checkpoint、事件或审计摘要。
- RPC 验证身份、状态和输入结构，非法状态不产生部分写入。

### 4.4 语音与外部依赖

- text 会话不能获取 voice 连接。
- WebSocket token 过期/篡改、非法事件、断线和上游失败均关闭资源并返回安全错误。
- ASR 最终文本只通过统一 Agent 输入流程推进状态。
- 模型非法 JSON、超时、限流，网页超时/污染和文档解析失败均有受控结果。
- 仅有 Wikimedia 公开知识通道时 readiness 为 `degraded`，不得标为完整联网研究就绪。

## 5. 人工验收

### Web

- 登录/退出和受保护路由。
- 首页双入口、创建向导、readiness 阻塞和错误恢复。
- 完整文字面试、SSE 断线恢复、结束和报告。
- 题库、收藏、简历、知识库、历史和设置。
- 键盘、焦点、窄屏、加载、空状态和错误状态。

### 真实语音设备

- 麦克风允许/拒绝、校准、开始、识别、思考、播报和打断。
- 静音、噪声、快速连续发言、网络切换、前后台和重连。
- Qwen 不可用、token 过期和 API 重启后的可理解提示。

### Tauri

- 登录持久化、HTTPS/WSS、麦克风、全屏、Wake Lock 和窗口行为。
- Native API 地址配置正确；安装包不含服务端 Key。

## 7. 测试数据

- 使用合成账号、岗位、简历、回答、音频和文档。
- 测试 Key 使用无权限占位符或专用受限凭据，不写入仓库和日志。
- 时间、UUID、模型输出和网络依赖应可注入或稳定模拟。
- 清理只针对显式测试资源，禁止模糊匹配删除共享环境数据。
