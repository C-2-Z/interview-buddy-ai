# 软件需求规格说明书

> 状态：当前｜维护者：产品与开发团队｜最后核验：2026-07-16｜代码基线：`main@6958ac3`｜事实源：前端页面、API 路由、Zod schema、服务层与验收测试

## 1. 范围与角色

本文定义当前已实现产品行为及其验收口径。未来能力只允许记录在[产品与技术路线图](产品与技术路线图.md)。

| 角色        | 权限与目标                                                   |
| ----------- | ------------------------------------------------------------ |
| 未登录访客  | 浏览首页，进入认证流程                                       |
| 已登录用户  | 管理个人设置、简历、知识库和面试数据，发起并完成面试         |
| 运维/开发者 | 在授权环境执行部署、诊断和恢复，不获得绕过用户隔离的产品权限 |

## 2. 用户流程

### UF-01 文字面试

登录 → 进入文字入口 → 填写岗位、难度、题量和可选上下文 → readiness → 创建 `coaching` 会话 → 回答/追问 → 结束 → 查看报告。

### UF-02 语音面试

登录 → 进入语音入口 → 完成设备与 readiness 校验 → 创建 `simulation` 会话 → 获取短期连接信息 → WebSocket 对话 → 结束/恢复 → 查看报告。

### UF-03 复盘与学习

历史记录 → 会话/报告 → 查看评分证据与建议 → 进入题库、简历或知识库继续练习。

## 3. 功能需求

| 编号  | 需求                                                                                     | 验收映射     |
| ----- | ---------------------------------------------------------------------------------------- | ------------ |
| FR-01 | 系统必须支持邮箱密码认证、会话恢复和退出；受保护页面必须拒绝未认证访问。                 | AC-01        |
| FR-02 | 用户必须能选择文字/语音入口并配置岗位、难度、题量、岗位描述及可选上下文。                | AC-02        |
| FR-03 | 创建前必须执行 readiness；阻塞项不得被前端静默绕过。                                     | AC-03        |
| FR-04 | 新会话必须固定 `agent-v3`；文字固定 `coaching`，语音固定 `simulation`。                  | AC-03、AC-04 |
| FR-05 | Agent 必须支持会话创建、获取、输入、活动、事件、结束、重试和工作区投影。                 | AC-04、AC-05 |
| FR-06 | 输入必须经过 schema、长度、复制题目和 Prompt 注入防护；重复 `inputId` 必须幂等。         | AC-06        |
| FR-07 | 评分必须基于持久化问答证据，输出结构化分数、优点、问题和改进建议。                       | AC-07        |
| FR-08 | SSE 必须支持游标重放；刷新或短暂断线后可从业务状态和事件恢复。                           | AC-05        |
| FR-09 | 语音必须使用短期令牌连接 Agent-only WebSocket，支持 ASR、TTS、控制事件、打断和错误反馈。 | AC-08        |
| FR-10 | 用户必须能浏览公共题库、题目详情、收藏和岗位 Skill。                                     | AC-09        |
| FR-11 | 用户必须能上传、查看和删除个人简历；支持的解析格式以路由校验为准。                       | AC-10        |
| FR-12 | 用户必须能管理知识文档、Brain、问答会话、搜索和知识图谱。                                | AC-11        |
| FR-13 | 用户必须能选择 Provider/模型，并加密保存个人 API Key。                                   | AC-12        |
| FR-14 | 用户必须能查看历史会话、当前工作区和最终报告，并删除自己的会话。                         | AC-13        |
| FR-15 | Web 与 Native 客户端必须共享业务 API；Native 构建不得包含服务端密钥。                    | AC-14        |

## 4. 非功能需求

| 编号            | 要求                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------- |
| NFR-01 安全     | 用户数据必须经过认证、所有权校验和 RLS/RPC 边界；凭据与正文不得进入日志、事件或 Checkpoint。 |
| NFR-02 可靠性   | 状态写入必须覆盖幂等、并发 claim、失败、刷新、断线和重试。                                   |
| NFR-03 性能     | 交互链路必须设置明确超时；大列表应分页；语音与 SSE 不得因慢消费者无限缓存。                  |
| NFR-04 可维护性 | 后端模块四层分离，前端功能独立 feature，路由保持薄入口。                                     |
| NFR-05 可观测性 | 错误必须结构化记录模块、路径、阶段和安全元数据，不记录敏感正文。                             |
| NFR-06 可访问性 | 关键操作支持键盘、可见焦点、语义标签和足够颜色对比；状态不能只依赖颜色表达。                 |
| NFR-07 可移植性 | Web 与 Native 的平台差异必须经运行时配置和平台适配层处理。                                   |
| NFR-08 可恢复性 | 业务表是事实源；Checkpoint 只恢复 Graph；事件只负责增量重放。                                |

## 5. 验收标准

| 编号  | 场景与通过条件                                                               |
| ----- | ---------------------------------------------------------------------------- |
| AC-01 | 未登录访问受保护路由会跳转认证；登录后能恢复目标页面。                       |
| AC-02 | 两个入口展示正确模式说明，创建参数可校验且错误可见。                         |
| AC-03 | 缺少模型、Key、数据库或语音能力时 readiness 返回明确阻塞，不创建半成品会话。 |
| AC-04 | 新文字/语音会话分别写入固定模式，版本为 `agent-v3`。                         |
| AC-05 | 提交输入后活动和 SSE 一致；刷新、重复请求和游标恢复不重复推进问题。          |
| AC-06 | 空白、超长、复制题目、注入文本和重复 `inputId` 均得到受控结果。              |
| AC-07 | 完成会话后报告可从持久证据重新读取，分数范围和结构满足 schema。              |
| AC-08 | 语音连接令牌过期、非法事件、断线和上游 ASR/TTS 失败都有可恢复错误。          |
| AC-09 | 题库列表、详情和收藏只返回允许公开或属于用户的数据。                         |
| AC-10 | 不支持格式、超限文件和跨用户简历访问被拒绝。                                 |
| AC-11 | 知识文档、Brain、QA、搜索与图谱遵守用户隔离和来源引用。                      |
| AC-12 | API Key 读取不返回明文；错误日志不泄露凭据。                                 |
| AC-13 | 历史、工作区、报告和删除均校验当前用户所有权。                               |
| AC-14 | Native 边界验证通过，产物中不存在服务端环境变量或密钥。                      |

## 6. 排除范围

当前不包含离线推理、后台录音、支付订阅、自动生产数据库修复、Redis/BullMQ generation Worker 和未验收的移动商店发布流程。
