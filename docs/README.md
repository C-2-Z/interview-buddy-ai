## 维护规则

1. 架构或业务契约变化时，同一提交更新相关文档。
2. 文档只描述当前实现或明确标记的未来计划，不混写已退役方案。
3. API 以 `api-server/src/app.ts` 和实际 `*.routes.ts` 为准；OpenAPI 生成物必须同步校验。
4. 数据库以不可变增量迁移为准，不回写历史迁移。
5. 临时方案、会议纪要和周报放入 `docs/` 下对应的过程材料目录，不与核心工程文档混排。
6. 每份核心文档顶部记录状态和最后核验日期。
