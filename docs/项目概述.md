# EZMock 项目概述

> 状态：当前｜维护者：项目团队｜最后核验：2026-07-16｜代码基线：`main@6958ac3`｜事实源：前后端路由、模块目录、运行配置与数据库迁移

## 1. 产品定位

EZMock 是面向求职者和学习者的 AI 面试练习平台。用户选择岗位、难度和面试模式后，系统通过 Agent 生成或选择问题、进行多轮追问、保存证据、逐题评分并生成综合报告。

平台的核心价值不是一次性问答，而是可恢复、可解释、可复盘的完整面试闭环。

## 2. 目标用户与场景

| 用户     | 主要目标                                       |
| -------- | ---------------------------------------------- |
| 求职者   | 在正式面试前练习表达、发现知识与结构化回答弱点 |
| 学习者   | 使用公共题库、知识库和复练能力巩固知识         |
| 项目成员 | 开发、测试、部署和维护平台能力                 |

典型场景包括文字辅导面试、沉浸式语音模拟、公共题库刷题、简历辅助、知识库问答、历史报告复盘和弱项复练。

## 3. 核心业务闭环

```text
认证
  → 选择文字或语音入口
  → 配置岗位、难度、题量、题库/简历等上下文
  → readiness 校验并创建 agent-v3 会话
  → Agent 选题、提问、追问和评分
  → 完成或提前结束会话
  → 生成报告、历史记录和可复练弱项
```

## 4. 产品模式

| 模式     | 固定策略     | 主要体验                                   |
| -------- | ------------ | ------------------------------------------ |
| 文字面试 | `coaching`   | 允许引导、追问和结构化反馈，强调练习与理解 |
| 语音面试 | `simulation` | 强调连续对话、真实节奏、打断处理和异常恢复 |

新会话唯一可写运行时为 `agent-v3`。Agent v1/v2 只允许用于历史兼容读取，不得恢复写链路。

## 5. 当前能力

- Supabase 邮箱密码认证与用户隔离。
- Agent readiness、会话创建、输入、活动、事件重放、结束、重试与工作区投影。
- SSE 事件恢复以及业务表、Checkpoint、事件表之间的职责分离。
- Qwen ASR/TTS 驱动的语音 WebSocket 面试。
- 公共题库、收藏、岗位 Skill 与题目详情。
- PDF/DOCX/TXT 简历上传、解析和管理。
- 文档知识库、RAG 问答、Brain、搜索与知识图谱。
- 用户级模型 Provider、模型与加密 API Key 设置。
- TanStack Start Web SSR、Native SPA 和 Tauri Windows 容器。

## 6. 技术全景

| 层级       | 当前技术                                                                |
| ---------- | ----------------------------------------------------------------------- |
| Web/SSR    | React 19、TanStack Start/Router/Query、Vite、Tailwind CSS 4、Radix UI   |
| API        | Node.js、TypeScript、Hono、Zod、consola                                 |
| Agent      | LangGraph、Postgres Checkpoint、DeepSeek/OpenAI/Anthropic 兼容 Provider |
| 语音       | Qwen Realtime ASR/TTS、`ws` WebSocket                                   |
| 数据与认证 | Supabase PostgreSQL、Auth、RLS、RPC                                     |
| 跨端       | Native SPA、Tauri 2、平台适配层                                         |
| 部署       | Web SSR 平台、独立 Node API、Supabase、Windows 安装包                   |

## 7. 系统边界

当前系统不承诺：离线面试、端侧 AI 推理、支付订阅、后台持续录音、自动生产迁移修复、可运行的 Redis/BullMQ 生成 Worker，以及未经配置验证的 Android 商店发布。

## 8. 核心术语

| 术语       | 含义                               |
| ---------- | ---------------------------------- |
| Session    | 一次面试会话及其冻结配置           |
| Agent run  | Agent 对一次输入的受控执行         |
| Activity   | 对外展示的会话活动和阶段进度       |
| Event      | 用于 SSE 重放的最小化事件          |
| Workspace  | 从业务数据投影出的当前面试工作区   |
| Checkpoint | LangGraph 恢复状态，不是业务事实源 |
| Brain      | 一组知识文档的逻辑集合             |
